Sign invoices with KEP and send them — without leaving Odoo

Qualified electronic signature and document exchange with your counterparties, through the Active Doc service

Version 19.0.1.0.1 · LGPL-3 · free · Odoo 19

⚠️ Before you install

  • Odoo must open over https. On an http page the browser switches off the cryptography the signing window needs, and a real organisation's key is bound to an https address only.
  • Odoo Online does not install third-party modules — use Odoo.sh or your own server.
  • You need an organisation cabinet on doc.aktiv.in.ua — created with one signature of your key; the free plan is enough to start.

If you came from 1C / BAS

In 1C and BAS the invoice is made in one program and signed in another — M.E.Doc or a separate e-document service — and the signed copy has to be found and filed back by hand. Here the button is on the invoice itself, the signing window opens inside Odoo, and the signed archive comes back to the same invoice.

What it does

  • Send for signature — on a posted invoice, act or delivery note: pick the printed form, the recipient comes from the partner card, preview the PDF
  • Sign inside Odoo — the Active Doc signing window opens in a dialog; no separate cabinet to log into
  • Send — to the counterparty's Active Doc cabinet by EDRPOU / RNOKPP, or as a link by e-mail; they sign without registering
  • Incoming — documents sent to your code appear by themselves; sign them, or reject with a reason the sender will see
  • Signed archive — once both sides have signed, the document, every signature and the verification protocol are attached to the invoice

How it is built

  • Your key never reaches Odoo — the key file and its password stay in the signing window; Odoo only learns that the document was signed
  • The API key stays on the server — never in the browser, never in the logs; document contents are not logged either
  • “Signed” is not taken on trust — the message from the window is checked for its origin, and the state is re-read from Active Doc
  • Every problem at once — before sending, the wizard lists everything that would block it, each with what to do
  • Standard Odoo only — depends on Accounting alone; works with any chart of accounts, with or without the Aktiv modules

Active Doc and its plans

Active Doc is a Ukrainian e-document service by the same author. Receiving, signing and rejecting documents, and the signed archive, are free and unlimited on every plan. The free plan sends up to 20 documents a month; larger plans are listed on the service's site. The module tells you when a limit is reached and never pays for anything on its own.

Which keys work: file keys of Ukrainian qualified trust service providers — Key-6.dat, *.jks, *.pfx — right in the signing window. With a hardware token, a cloud key or Diia.Signature, sign the document on the czo.gov.ua site and upload the signature file into the same window.

Getting started

Create an organisation cabinet on Active Doc (one signature with your key), create an API key there under Organisation → API keys together with the address of your Odoo, and paste the key into Settings → Invoicing → Active Doc. Check connection shows the organisation, the plan and whether the signing window will open from your Odoo address.

Рахунки підписуються КЕП і йдуть контрагенту — не виходячи з Odoo

Кваліфікований електронний підпис і обмін документами з контрагентами через сервіс Active Doc

LGPL-3 · безкоштовно · Odoo 19

⚠️ Перш ніж встановлювати

  • Odoo мусить відкриватися за https. На http-сторінці браузер вимикає криптографію, потрібну вікну підпису, а ключ справжньої організації прив'язується лише до https-адреси.
  • Odoo Online сторонніх модулів не встановлює — потрібен Odoo.sh або власний сервер.
  • Потрібен кабінет організації на doc.aktiv.in.ua — створюється одним підписом вашого ключа; для початку досить безкоштовного тарифу.

Якщо ви прийшли з 1С / BAS

У 1С і BAS рахунок робиться в одній програмі, а підписується в іншій — M.E.Doc чи окремому сервісі ЕДО, — і підписаний примірник потім шукають і підшивають руками. Тут кнопка — на самому рахунку, вікно підпису відкривається в Odoo, а підписаний архів повертається до того ж рахунку.

Що він робить

  • Надіслати на підпис — на проведеному рахунку, акті чи накладній: друкована форма, отримувач із картки контрагента, перегляд PDF
  • Підпис в Odoo — вікно підпису Active Doc відкривається тут же, у діалозі; входити в окремий кабінет не треба
  • Надіслати — у кабінет контрагента в Active Doc за ЄДРПОУ / РНОКПП або посиланням у листі; він підписує без реєстрації
  • Вхідні — документи, надіслані на ваш код, з'являються самі; підписати або відхилити з причиною, яку побачить відправник
  • Підписаний архів — щойно підписали обидві сторони, документ, кожен підпис і протокол перевірки прикріплюються до рахунку

Як він збудований

  • Ваш ключ до Odoo не потрапляє — файл ключа й пароль лишаються у вікні підпису; Odoo дізнається лише, що документ підписано
  • Ключ API — лише на сервері — ні в браузері, ні в журналах; вміст документів теж не журналюється
  • «Підписано» не на слово — повідомлення вікна перевіряється за адресою відправника, а стан перепитується в Active Doc
  • Усі проблеми одразу — перед надсиланням майстер показує все, що завадить, і що з кожним робити
  • Лише штатний Odoo — залежить тільки від Бухгалтерії; працює з будь-яким планом рахунків, з модулями «Актив» або без них

Active Doc і тарифи

Active Doc — український сервіс електронного документообігу того самого автора. Отримання, підпис і відхилення документів, а також підписаний архів — безкоштовно й без меж на будь-якому тарифі. Безкоштовний тариф надсилає до 20 документів на місяць; більші тарифи — на сайті сервісу. Модуль каже, коли межу вичерпано, і ніколи нічого не оплачує сам.

Які ключі підходять: файлові ключі українських ЦСК — Key-6.dat, *.jks, *.pfx — прямо у вікні підпису. З апаратним токеном, хмарним ключем чи Дія.Підписом документ підписують на сайті czo.gov.ua, а файл підпису завантажують у те саме вікно.

Як почати

Створіть кабінет організації в Active Doc (один підпис вашим ключем), там же створіть ключ API в Організація → Ключі API разом з адресою вашого Odoo і вставте його в Налаштування → Виставлення рахунків → Active Doc. Перевірити з'єднання покаже організацію, тариф і чи відкриється вікно підпису з адреси вашого Odoo.
